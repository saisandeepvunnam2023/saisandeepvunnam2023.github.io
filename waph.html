Web Application Program and Hacking

Individual Project: Professional Profile Website

Instructor: Phu Phung

Course Overview

This course begins with the essentials of web application development-building the front end using HTML5, JavaScript and CSS, and the back end with PHP and MySQL. You'll then dive into common web-app vulnerabilities and attack techniques through hands-on labs. Finally, we'll cover secure-coding principles and best practices to help you write applications that resist those threats.

Topics Covered

  • Introduction to the Course - Web Application Program and Hacking
  • Development Environment Setup
  • HTTP Protocol and Basic Web Application Programming
  • Front-end Web Development
  • Client-Side Security and Server-side Technologies, Security and Standards
  • Web Application Security and OWASP Top 10

Technology Requirements

To work through the hands-on exercises, labs, and projects, make sure you have a laptop or desktop that can run a Linux VM-then install VirtualBox and set up an Ubuntu 22.04 virtual machine.
